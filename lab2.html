Cómo usar los archivos en Logisim

  1. Descarga el .circ (compuertas = cada AND/OR/XOR/NOT dibujada; bloques = usa Adder/Subtractor/Multiplier/Divider de la librería Aritmética).
  2. Ábrelo en Logisim (2.7.x, Logisim-evolution o logisim.app en el navegador) con File → Open.
  3. Herramienta de la manita: haz clic en los pines de entrada para poner 0/1 y mira las salidas.
  4. En la versión de compuertas las conexiones usan túneles (mismo nombre = mismo cable) para que el esquema quede ordenado.

¿Funciona en GitHub Pages?

Sí. GitHub Pages solo sirve archivos estáticos, pero el .circ es texto XML: el JavaScript lo escribe en memoria, lo convierte en un Blob y el navegador lo descarga. Todo ocurre en tu equipo; no se envía nada a ningún servidor.
