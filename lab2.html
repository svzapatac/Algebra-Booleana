Sumador, restador, multiplicador y divisor de 4 bits

Elige la operación y el tamaño. La página calcula el paso a paso, genera el circuito Logisim (.circ) en tu navegador y te da el plano para armarlo con chips TTL.

Descargar para Logisim

Los archivos se crean al instante en tu navegador (no hay servidor). Se abren con File → Open en Logisim.

Vista por etapas en vivo

Haz clic en los interruptores de entrada para cambiar 0/1. Cada compuerta del circuito muestra su valor en vivo (azul = 1, gris = 0). Es el mismo circuito que se descarga en el .circ.

Editor estilo Logisim (todo dentro de la página)

Elige una pieza de la paleta y haz clic en el lienzo. Con 🖐 Mano: arrastra de un pin a otro para tender un cable, clic en un interruptor para cambiarlo, arrastra una pieza para moverla y pulsa Suprimir para borrar. Todo se simula en vivo.

Original vs reducida con métodos

Cada salida se escribe como tabla de verdad de las 2N entradas. Original = suma de todos los minitérminos. Reducida = Quine-McCluskey (en la división, B = 0 se toma como indiferente). Estructural = la construcción por etapas (sumador completo, etc.).

¿Funciona en GitHub Pages?

  
Sí. GitHub Pages solo sirve archivos estáticos, pero el .circ es texto XML: el JavaScript lo escribe en memoria, lo convierte en un Blob y el navegador lo descarga. Todo ocurre en tu equipo; no se envía nada a ningún servidor.
